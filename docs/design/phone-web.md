# 手机网页界面基准

0.3.1 按需拍摄：相机空态保留，在选手接近终点时用一个「开启相机并录像」主按钮启动；取消原先「准备整组录像」按钮和发令前录像门槛。保留整组原片、多人选帧、断网补传及设备成绩区域。

0.3.0 沿用已有配色与单列相机工作区，功能改为整组录像、多人选手选择和独立证据提交。初始文案为「等待电脑创建组次」，状态区增加组员设备成绩；不再把浏览器视频时间当成官方用时。原下文的单人文案属于 0.2.0 设计参考。

视觉参考：`phone-concept.png`，由内置 Image Gen 生成，作为设计参考，不是运行时背景或按钮图片。网页中的全部文字、控制和图标均由代码绘制，视频区域使用真实摄像头/录像。

生成简报：创建 390×844 的完整中文终点相机网页；沿用深色 #0B141C、表面 #14202B、文字 #EFF6F8、辅助文字 #A9BBC9 和主操作 #C0F069。初始界面含「终点相机」「电脑未连接」「等待电脑选择选手」「先连接电脑，再提前录像」、4:3 相机预览、实际帧率和网络同步、开启相机/准备录像、恢复录像/连接设置、底部精度说明。无营销区块、虚假成绩或额外导航。

设计约束：20px 手机左右边距；相机画面是主要视觉区域；主按钮突出、准备按钮在条件不足时禁用；状态、录像、判读和保存提示使用同一组件体系。较大屏幕保持有上限的单列工作区。

运行时变化：连接状态、选手、实际帧率、同步统计、相机预览和录像会替换初始空态。判读状态增加媒体时间轴、前后帧、放大、参考线、确认及返回相机操作。没有加载图片来伪装真实视频。

验证方法：在 390×844 和 768×1024 Playwright Chromium 中检查初始屏、弹窗、录像、判读、恢复和断线补传；Browser 插件不可用，故使用 Playwright。截图存放在任务的外部可视化目录，未放入源代码。
