# 0.4.1 操作指南

## 准备

Windows、Timy3、终点手机在现场使用；手机与电脑同一Wi-Fi，无需互联网或新增同步硬件。手机固定在终点线延长线上侧拍，终点平面需在画面里成为清晰竖直参考线。保持光线、焦距和机位稳定；没有固定侧拍确认的候选不会自动确认。

打开程序，确认 USB 已连接；不要同时运行占用 Timy3 的 ExcelWriter。第一次使用核对设备精度和 CUT/UP/ROUND，软件不自动更改设备。二维码入口和证书方法见《浏览器部署》。升级后刷新网页并重新扫码，勿清理网站数据。

## 一组选手

1. 手机先配对；模型从电脑本地预加载，相机保持关闭。确认显示「本地躯干模型就绪」。模型失败仍能录像，但须人工复核或启用设备备份。
2. 电脑勾选多人，填写组名、精度和舍入，勾选已核对，再创建组次。发令后名单锁定。
3. 点击「进入待发令」，Timy3 按一次 START，C0/C0M 保存全组共同起跑。起跑前/重复起跑只记录和告警。
4. 接近终点前，手机设置参考线、左右通过方向、区域上下边界及固定侧拍确认。首次授权和模型启动须留足时间。可先点击「手动预览并校准终点线」观察实际画面，也可直接点击「开启相机并录像」；开始录像后设置冻结。
5. 录像持续到最后一人。自动候选使用胸腹躯干掩膜前缘；头颈、手臂和腿脚不参与边缘。多人接近、身份关联不唯一、回退、缺关键帧会标记复核，不能据此猜测号码。
6. 电脑切到「视频候选与来源复核」，选候选及选手，绑定。候选显示估计秒数及未核验原因；未达标不进入有效排名。正常候选也须原片及所有证据后台核验完成。
7. 光电门接 C1 或手动 STOP，每个事件单独保存。现场页选择事件和选手「匹配所选号码」，仅登记备份。复核页选择选手、填写原因，再点「启用已匹配光电门备份」才能形成采用成绩。
8. 最后一人过线后结束整组录像。若仍有选手/事件待处理，网页提示证据可能不完整。逐人选帧，必要时放大或拖动，保存此人的过线证据。人工更正追加判读版本；换帧后若没有该帧的有效采集映射，视频成绩回到待核验，不能用文件PTS直接补算。
9. 处理 DNS/DNF/DSQ、误按及多余视频候选。点击「结束本组」时若仍有未处理选手/事件或未结束录像，程序列出数量，确认「结束并保留待复核」后即可继续下一组。未匹配事件原样保留，不自动标记误按；未处理选手保留待复核，不猜测DNS/DNF或成绩，已有成绩、状态和原始录像保留。上一组原片补传不阻塞下一组准备。

## 来源、更正与排名

现场成绩显示采用时间、视频候选、光电备份、差值和当前来源。视频和光电可能对应不同身体部位，不强制把差值归零。

撤销、忽略、交换、切换来源均填写原因。光电号码配错可撤销重配；已采用备份先撤销其绑定，核对后重配并明确重新启用。撤销已采用备份不会自动切到视频；之后切回视频需要明确确认，并且该视频须通过核验。视频绑定配错可撤销后重新绑定；所有原始事件保留。

人工按键存在反应误差；光电也可能被手臂先触发。采用备份是裁判的明确决定，来源单独标记。已确认的成绩采用组次冻结的整数舍入配置，显示、CSV、排名一致，同分并列1、1、3。旧版浏览器估算不混入新排名。CSV保留两种时间、差值、核验状态、配置和当前来源。

## 断线与文件

发令后手机断线不影响 Timy3 接收。手机前台继续录制并保存到 IndexedDB；恢复连接后自动重试。切后台或锁屏可能停止相机，本版会标记提前结束，不假装录像完整。

先回传候选与前/判定/后帧、躯干掩膜及元数据，后补传同组原片一次。上传按断点和SHA256校验。电脑确认前不要删除原片，确认后软件也不自动删除。若原片画面匹配不唯一，保留候选并人工复核，不能靠录像启动按钮时刻加文件PTS计算主成绩。

网页「恢复本机录像」可恢复旧组，原片下载可另外备份。数据目录含数据库、原始日志、证据及本机证书私钥；私钥不要上传。数据库升级前自动生成pre-v3备份。

## 候选列表为空时

视频复核页可直接选组次，并显示是否录像、采集与已分析帧数、可见目标及躯干像素、手机候选/保存数、电脑收到数与最后检测/上传错误。没有实测配置只会阻止自动确认，不会隐藏候选。手机网页标题应为v0.4.1；更新后刷新并重新扫码连接，不要清理网站数据或删除原片。

## 当前交付范围

没有附带任何真实达标配置，自动视频确认保持关闭。本版可检测并保存候选、人工匹配与复核、明确启用光电备份；未完成真机与现场精度验收。不得将两位小数显示理解为已达到10ms精度。
