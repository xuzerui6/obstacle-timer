# 手机网页部署与使用 / 0.4.0

当前默认终点端为网页，苹果使用 Safari、安卓使用 Chrome 等现代浏览器，无需安装原生 App。Windows 计时程序同时提供安装指引和安全相机页面。

## 首次连接

1. Windows 与手机使用同一路由器；建议给电脑保留固定的局域网 IP。
2. 到电脑「设备与配对」，选择真实局域网地址。手机系统相机扫描二维码，打开 `http://电脑IP:8765/setup#secret=...`。
3. 按网页指引安装**这台电脑生成**的本地 CA 公共证书。
4. 苹果手机还需在「设置 → 通用 → 关于本机 → 证书信任设置」中开启完全信任。安卓在系统「安装 CA 证书」入口导入 `.cer`。
5. 点击「打开终点相机」，进入 `https://电脑IP:8766/phone/`。配对码在 URL 片段中传递，成功配对后从地址栏移除。
6. 手机保持电脑已连接即可，相机默认关闭。电脑先创建组次并发令；选手接近终点时点「开启相机并录像」，此时才申请相机权限。首次使用留足授权和启动时间。

HTTP 相机权限不能通过普通局域网 IP 页面获得。不要用忽略安全限制的浏览器启动参数作为真实部署方案。测试中 Playwright 的忽略证书错误仅用于自动化隔离环境，不能证明手机已经信任证书。

Windows 防火墙需允许本程序在专用网络使用 TCP 8765 和 8766。路由器不能开启终端之间的访问隔离。电脑换网、增加网卡或更换地址后，重新启动程序以更新服务器证书中的 IP。

## 本地躯干检测与成绩来源

配对后预加载随电脑分发的BodyPix模型及WASM，不从CDN下载，不开启相机。点击按钮后才开始采集和录像。开始前设置终点线、方向、区域，确认固定侧拍；采集后冻结。页面显示模型、缓冲及候选状态。没有真实达标配置时，候选一直待核验；光电门绑定不会自动成为主成绩。

具体来源切换与配置门槛见《操作指南》《精度验证》。v3不使用录像按钮时刻加PTS作为主计时依据，rVFC呈现时钟也必须经过机型/模式完整实测才能批准。

## 网页录像与判读

- 点击「开启相机并录像」才请求摄像头并启动 MediaRecorder，显示真实 `getSettings().frameRate`。请求高帧率不代表实际获得该帧率，不预设所有手机有 120/240 fps。
- 保存首个 IndexedDB 分片后登记录像。新组不以录像或网络同步作为发令条件，录制晚于起跑也不会重置共同起跑；登记消息丢失时通过 HTTP 重试。
- 浏览器无法像原生采集程序一样证明首个传感器帧已编码落盘，因此记录分片、预览时刻及录制启动时刻作为诊断证据，不宣称其为硬件采集时间。
- 手机手动开启后连续拍到最后一人，起跑消息不会自动开相机，也不按消息到达时刻计时。本版先用手动，未接入光电门自动开启。
- 结束录像后，从 MP4 样本或视频专用 WebM 数据中提取实际媒体时间点。选帧时读取浏览器真实呈现画面的 `mediaTime`，保存截图及所选 PTS。
- 「上一帧／下一帧」使用实际媒体索引；支持拖动时间轴、放大、移动画面和调整终点参考线。浏览器未能呈现目标帧时不允许把请求时间冒充已呈现时间。
- 确认后，先保存本地 outbox，再提交各人的截图判读，最后上传一份整组原片。支持断点和 SHA256 校验。判读不会修改 Timy3 设备成绩，电脑确认后本机文件仍不自动删除。
- 「返回相机，准备下一组」切回录像操作；「恢复本机录像」可恢复整组原片，选择不同选手分别留证，判读版本与成绩版本独立保存。

## 精度与保存边界

0.3.1 的正式计时完全采用 Timy3 起终点设备时刻。`performance.now()`、网络 RTT、录像启动及视频 PTS 不再进入成绩计算。浏览器的采集/编码/呈现延迟尚未校准，因此视频帧与设备事件的精确对齐不作保证；裁判按画面确认号码和证据。当前使用设备手动按键，仍有人为反应误差，不承诺真实冲线准确到 0.01 秒。

浏览器会在权限、帧率、编码容器、后台行为和存储配额方面限制摄像头。请保持页面前台，避免锁屏、隐私浏览、清理网站数据或在比赛途中更换电脑 IP。应用检测到离开前台时会尝试结束并保存录像，但操作系统强制终止网页仍可能留下未封装分片。

IndexedDB 属于该 HTTPS 地址的网站存储；电脑地址变更会成为不同来源。录像补传前不要更换访问地址、清除网站数据或删除浏览器。可以手动「导出本机原片」另存备份。

## 证书文件

公共 `.cer` 和苹果 `.mobileconfig` 仅包含 CA 公钥证书。CA 私钥留在电脑数据目录的 `certificates/local-camera-ca.pfx`，不通过网页提供，也不包含在安装包中；不要把这个私钥文件分享出去。卸载本项目的手机 CA 信任可在对应系统的证书/描述文件设置里移除。

## 开发

`scripts/build-web.ps1` 构建 `web/phone`。Windows 项目把 `dist/` 作为静态文件一起打包；用户无需 Node.js、开发服务器或公网托管。

`mobile/ios` 和 `mobile/android` 保留先前 v1 原生实现供参考，未适配本次 v3，不作为本次手机交付。
